# Dragon Reef Arcade

Complete self-contained entertainment-credit arcade demo.

## Included
- Responsive lobby for phone/tablet/desktop
- Selectable fish games: Dragon Reef, Mermaid Bay, Ocean Hunter, Buffalo Deep
- Selectable slot games: Fire Vault, Golden Buffalo, Dragon Fortune, Neon 7s
- Fish-game canvas gameplay
- Slot-style reel gameplay
- Local entertainment-credit wallet and transaction history
- Player profile/name
- Sound toggle
- No cash-out, purchasing, deposits, prizes, or real-money wagering

## Run
Install Node.js 18+.

```bash
npm start
```

Open `http://localhost:3000`.

For GitHub Pages, the `public/` directory contains the entire browser application. Copy its contents to the repository root (or configure your Pages workflow accordingly).

## Important
Entertainment credits only. This build intentionally has no payment processor, cash redemption, gambling wallet, or prize system.
